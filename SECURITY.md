# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x.x   | ✅         |
| < 1.0.0 | ❌         |

---

## Reporting a Vulnerability

If you discover a security vulnerability in FitVerse, please do **not** create a public GitHub issue.

Instead, report it privately by contacting the repository owner.

Please include:

* Description of the vulnerability
* Steps to reproduce
* Potential impact
* Suggested fix (if available)

Security reports will be reviewed as quickly as possible.

---

## Security Features

FitVerse currently includes:

* JWT Authentication
* Password Hashing
* Helmet Security Middleware
* Express Rate Limiting
* Environment Variable Protection
* CORS Configuration
* Input Validation

Additional security improvements will be added in future releases.
